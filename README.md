# Otavio Zanon - Portfolio

Minimalist terminal-inspired portfolio built with React, TypeScript, and modern web technologies.

## 🚀 Features

- Single Page Application with React Router
- Multi-language Support (PT-BR / EN-US)
- Dark/Light Theme with persistent preferences
- Smooth Animations powered by Framer Motion
- Contact Form with FormSubmit integration
- Responsive Design with TailwindCSS
- Type-Safe with TypeScript

## 🛠️ Tech Stack

- React 18 + TypeScript 5 + Vite 5
- TailwindCSS 3 + Framer Motion 12
- React Router DOM 7 + i18next
- Lucide React + React Icons
- FormSubmit (contact form)

## 📁 Project Structure

```
src/
├── components/      # React components
├── constants/       # App constants
├── hooks/           # Custom React hooks
├── i18n/            # Internationalization
├── pages/           # Route pages
├── types/           # TypeScript types
└── utils/           # Utility functions
```
